Executive Dashboard

An interactive research lab on Transfermarkt player-scores: archetypes, market-value models, XI search, MIP allocation, and a bid/pass policy. Educational research, not transfer advice.

Questions that must have graphs

  1. Do archetypes differ in value and playing style?
  2. Does informed search match or beat uninformed search for XI quality at a node budget?
  3. Does a tuned GB beat linear regression on next value?
  4. Does a 6–8 feature scorecard match the full model?
  5. Does MIP under B beat “buy the top predicted values until broke”?
  6. Do bandits/Q-learning improve cumulative undervalued signings vs greedy, same B?

Data Freeze

Big-5 player-seasons, time split, and leakage rules. Raw CSVs stay out of Git.

Methodology notes

  • Time split by season, never a random row split.
  • Do not use players.market_value_in_eur or highest_market_value_in_eur as a same-window feature.
  • Targets come from player_valuations dated after the season cutoff.
  • Minimum 10 appearances in a Big-5 club season (GB1, ES1, IT1, L1, FR1).

Archetype Lab

Member A. Cluster train players from rolling stats without market value in the fit, then profile clusters by later value and position.

When python -m src.pipeline cluster has written labels, this page will show cluster profiles (goals/90, assists/90, cards/90, minutes, age, later median value).

Methodology notes

  • Fit on train rolling stats only.
  • Value is used after the fact to profile clusters, never inside k-means / GMM.

Forecast Lab

Member A. Weekly Big-5 goals with STL, Holt-Winters, and ARIMA. Optional map into budget B.

When python -m src.pipeline forecast has written budget.json, this page will show holdout MAPE and the implied transfer budget.

Methodology notes

  • If the series is unstable, keep B as a user input on Squad Builder and still report the forecast.

Experiment Board

Member B. R0 ridge, R1 gradient boosting, C1 undervalued classifier, S1 LSTM/1D-CNN. Locked metrics: MAE/RMSE/Spearman and PR AUC / ROC AUC / Brier — not accuracy.

When python -m src.pipeline score has written comparison tables, this page will show R0 vs R1 vs S1 on the locked test seasons.

Methodology notes

  • Threshold for “undervalued” is frozen on validation residuals, never retuned on test.
  • Portrait CNNs are out of scope.
